# Paths and inputs

Edit the hard-coded paths inside the scripts before running, or use this file as a checklist.

Required source data:
- TCGA / UCSC Xena cancer folders containing gene-expression matrices and clinical/survival files.
- MSigDB Hallmark, GO Biological Process, and Reactome GMT files.

Recommended output roots:
- `AIDO-h-Biology-II-AllCancers-MultiDB/`
- `AIDO-h-Biology-II-RandomPilot/`
- `AIDO-h-Biology-II-RandomGlobal-SizeBin-T300/`
- `AIDO-h-Biology-II-ReviewerAnalyses/`
- `AIDO-h-Biology-II-Manuscript-Figures/`

Large generated supplementary tables are intentionally not stored in this GitHub repository.
They can be generated locally using the scripts and then supplied with the manuscript submission.
